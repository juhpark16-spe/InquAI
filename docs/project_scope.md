# 프로젝트 범위: 핵심 이야기와 기능 분류 (발표·시연 기준)

기능은 지우지 않고, **발표와 시연에서 무엇을 앞에 세울지**를 정한 문서입니다 (2026-11-26).
시연 순서는 `docs/demo_scenario.md`, PPT도 이 문서의 순서를 따릅니다.

## 핵심 이야기 (한 문장)

> **"AI가 답할 수 있는 문의는 바로 답하고, 위험한 문의는 사람에게 넘기며, 사람이 고친 결과는 다시 AI를 좋게 만든다."**

세 부분으로 나눠 말합니다.

| 부분 | 말할 것 | 보여 줄 근거 |
| --- | --- | --- |
| ① 바로 답한다 | 분류 모델 + FAQ 검색 + LLM이 **FAQ에 있는 근거로만** 답함 | 자동 답변 장면, FAQ 검색 평가 (맞는 FAQ가 없으면 추천하지 않음) |
| ② 위험하면 사람에게 | 규칙 → LLM → 답변 검사 세 겹. 긴급·불확실·주입 문장은 LLM을 기다리지 않고 사람에게 | 긴급·주입 장면, AI 실행 로그, 에이전트 평가 (주입·보상 사례 16번 × 3문장에서 지급·승인 확정 0번) |
| ③ 사람의 수정이 AI로 | 상담원이 고친 분류·초안이 쌓여 재학습 데이터와 FAQ 후보가 됨 | AI 초안 분석, 재학습 현황 (재학습 뒤 직접 쓴 평가 93.3% → 95.8%) |

## 기능 분류

### 주인공 — 시연 시간의 대부분, PPT의 중심 (AI가 하는 일)

| 기능 | 화면 | 이야기 |
| --- | --- | --- |
| 유형·감정 분류 (KoELECTRA 분류 모델 2개) + 긴급도 | 문의 상세 'AI 분석' | ① |
| FAQ 검색 (KURE-v1 + ChromaDB) · 문의 쓰는 중 FAQ 추천 | 문의하기 | ① |
| 처리 방식 판단 (LangGraph: FAQ 검색 → 규칙 → LLM → 도구) | AI 실행 로그 | ① ② |
| 자동 답변 + 답변 검사 (지급·승인 확정 표현 차단) | 고객 대화 | ① ② |
| 규칙 우선 연결 (긴급·확신도 낮음·기타 → 사람) · 주입 방어 | AI 실행 로그 | ② |
| 상담원용 AI 초안 (처리 기록·주문 정보를 근거로) | 문의 상세 답변 칸 | ② ③ |
| AI 초안 분석 · 재학습 현황 · FAQ 후보 찾기 | 관리자 AI 관리 | ③ |

### 조연 — "상담원이 화면 하나에서 처리한다"는 한 장면으로

| 기능 | 화면 |
| --- | --- |
| 문의 상세: 주문 정보 요약, 취소·교환·반품 요청 카드, 승인 | 문의 상세 |
| 담당자 자동 배정 · 알림(🔔) · 답변 기한 · 처리 대기열 | 문의 상세·목록 |
| 대시보드 '지금 처리할 일' | 대시보드 |

### 배경 — 시연에서는 말하지 않거나 한 줄로 (질문이 나오면 보여 줌)

| 기능 | 왜 있나 (질문 받으면) |
| --- | --- |
| 중복 승인 취소 · 배송지·옵션 변경 · 부분 취소 · 반품 회수 접수 | AI 초안이 "실제로 처리된 결과"를 근거로 쓰게 하려고 |
| 환불 계좌 칸 (암호화 저장, AI에 넘기지 않음) | 개인정보를 AI와 분리한 예시 |
| 확인 후 다시 안내 | "확인 후 안내드리겠습니다"를 잊지 않게 |
| 주문·배송, 고객 조회, 재고 현황 (조회 전용) | 쇼핑몰 연동 시뮬레이션. 상담원이 다른 시스템을 열지 않게 |
| 답변 문구, 상담원 관리, 작업 기록, 공유 메모 | 운영에 필요한 기본 기능 |
| 쇼핑몰 회원 로그인 · 내 쇼핑 | 주문에서 바로 문의 (주문번호 자동) |

## 시연 시간 배분 (장면 합계 7분 10초, 화면 전환 포함 약 7분 30초)

| 구분 | 장면 (`docs/demo_scenario.md`) | 시간 | 비율 |
| --- | --- | --- | --- |
| 주인공 | 1 소개 · 2 자동 답변 · 3 위험하면 사람에게 · 7 사람의 수정이 AI로 · 9 마무리 | 4분 | 약 56% |
| 조연 (AI 초안 포함) | 4 처리 요청은 초안으로 · 5 상담원 처리 · 6 고객 확인 · 8 대시보드 | 3분 10초 | 약 44% |
| 배경 | 부록 장면 (녹화하지 않거나 질의응답용) | 0분 | - |

장면 5(상담원 처리) 안의 'AI 초안 다시 만들기'도 주인공 기능이라, 실제로 AI를 보여 주는 시간은 5분 가까이 됩니다.

## 발표에서 지킬 것

- **숫자는 조건과 함께**: "외부 테스트 98.1%"는 AI Hub 문장 기준이고, 실제 고객 글(짧고 맞춤법이 틀림)에서는 낮아질 수 있다고 먼저 말합니다.
- **기능 개수를 자랑하지 않기**: 메뉴를 하나씩 돌지 않습니다. 배경 기능은 "상담원이 다른 시스템을 열지 않게 조회 화면도 있다" 한 줄로 충분합니다.
- **한계와 개선 방향 1장**: 98%가 나온 조건, 실서비스라면 바꿀 것 (AI 처리 대기열, PostgreSQL, 열쇠 관리 서비스, DB 구조 변경 도구).
