## softmax와 sigmoid 비교 (2026-11-26, 실험 · 서버는 softmax 그대로)

지금 모델은 **softmax + 교차 엔트로피**(유형 8개 확률의 합 1, 문의당 유형 하나)입니다. 유형마다 따로 0~1을 내는 **sigmoid + 이진 교차 엔트로피**를
같은 데이터·설정(seed 42, 라벨 스무딩 0.1, 추가 학습 309건)으로 학습해 비교했습니다 (`train.py --loss bce`, 모델 `models/category_sigmoid_s42`).

| 평가 | softmax (지금) | sigmoid (실험) |
| --- | --- | --- |
| 내부 평가 2,648 정확도 | 97.5% | 97.4% |
| 외부 테스트 753 정확도 / Macro F1 | **98.1%** / 0.981 | 97.9% / 0.978 |
| 실전 100 정확도 | **98.0%** | 97.0% |
| 직접 쓴 평가 120 정확도 | 95.0% | **97.5%** |
| 확신도 0.8 미만으로 넘긴 비율 (외부) | 1.5% | 1.5% |
| **오답 중 0.8 기준으로 걸러낸 비율 (외부)** | **42.9%** (14개 중 6) | 31.3% (16개 중 5) |
| 확신도 평균 정답 / 오답 (외부) | 0.93 / 0.77 | 0.96 / 0.82 |
| 보정 오차 ECE (외부, 낮을수록 확신도 = 실제 정답률) | 0.067 | **0.032** |
| 관계없는 문장 15개 중 0.8 이상으로 잘못 확신 | 9 | 9 |
| 관계없는 문장을 '기타'로 (→ 규칙으로 상담원) | 4 | **9** |
| 여러 요청 문장 6개에서 두 유형 모두 0.5 이상 | 0 | 0 |

- **정확도는 비슷합니다.** 세트마다 이기는 쪽이 달라 seed 하나로는 차이를 말할 수 없습니다 (seed 사이 흔들림 ±0.2%p, 실전·직접 쓴 세트는 1문장 = 1%p, 0.8%p).
- **안전장치(확신도 0.8 미만 → 상담원)에는 softmax가 낫습니다.** sigmoid는 틀릴 때도 확신도가 높아(오답 평균 0.82) 오답을 덜 거릅니다.
- **sigmoid가 나은 점**: 확신도가 실제 정답률에 더 가깝고(ECE 절반), 관계없는 문장을 '기타'로 보는 경우가 많아 규칙으로 상담원에게 더 잘 넘어갑니다.
- **여러 요청 문장은 둘 다 하나만 고릅니다.** 학습 데이터가 문의당 정답 하나라, sigmoid로 바꿔도 '여러 유형 동시에'는 배우지 못했습니다 (예상대로).
- **결론: 서버는 softmax를 그대로 씁니다.** 시스템(담당자 배정·티켓·규칙·FAQ 보정)도 유형 하나를 전제로 합니다.
  sigmoid는 여러 요청에 정답 여러 개를 단 데이터를 모으면 다시 시도할 만합니다 (그때는 유형별 기준값과 seed 3개 평균으로 비교).
- 비교 숫자는 실험 스크립트로 같은 예측 코드(`predict.py`, 모델 설정의 `problem_type`으로 sigmoid/softmax 선택)를 써서 냈습니다. 외부 테스트 원문은 결과에 넣지 않았습니다.

## 재현 방법

데이터 파일은 실행 순서에 따라 바뀌므로, 현재 모델과 같은 데이터를 만들려면 이 순서를 따릅니다.

```bash
# 문의 유형 (category_aug_s42)은 docs/retraining.md "다시 만들기" 참고 (아래 데이터 + 추가 학습 데이터, seed 42)
# 이전 모델 (category_ev_s123): 생성 기타 문의 없이 만든 데이터
python backend/training/prepare_data.py --supplement data/supplement/web_inquiries.csv
python backend/training/prepare_qa_data.py
python backend/training/train.py --data data/raw/inquiries_with_qa.csv --label-column category --seed 123
python backend/training/evaluate.py --label-column category --test-file data/test/external_test.csv --report-name category_external
```

- 지금 `data/raw/inquiries_with_qa.csv`에는 생성 기타 문의 561건이 들어 있어, 위 첫 줄 없이 학습하면 현재 모델과 데이터가 다릅니다.
- 같은 데이터·seed라도 GPU 계산 방식 때문에 점수가 소수점 수준으로 다를 수 있습니다.
- 학습 결과는 `models/<라벨>_classifier`에 저장되어 기존 모델을 덮어씁니다. 비교 실험은 `--output-dir`로 다른 폴더에 저장합니다.

## 버전 이름 규칙

`<라벨>_<실험 이름>_s<seed>` 또는 `<라벨>_v<번호>`. 실험 이름과 평가 보고서 이름(`evaluation/<이름>_*.json`)을 같게 맞춥니다.
