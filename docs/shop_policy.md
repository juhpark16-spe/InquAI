# 가상 쇼핑몰 운영 정책

이 프로젝트는 실제 쇼핑몰이 아니라 **가상의 의류·잡화 온라인 쇼핑몰**을 기준으로 만듭니다.
아래 값은 국내 온라인 쇼핑몰에서 흔히 쓰는 수준으로 임의로 정한 것이며, 실제 회사의 정책이 아닙니다.

- 이 문서가 **정책의 기준**입니다. 정책을 바꿀 때는 이 문서를 먼저 고치고, 아래 "쓰는 곳"을 함께 맞춥니다.
- 쓰는 곳
  - FAQ: `data/faq/faqs.csv` (각 항목 옆의 FAQ 번호). 바꾸면 서버를 다시 켤 때 FAQ 검색 벡터가 새로 계산됨
  - LLM 답변: FAQ에 있는 내용만 근거로 답함 (`backend/ai/prompts.py`)
  - 정책 값(취소 가능 상태·반품 기한·배송비·환불 영업일 등): `backend/services/policy.py` 한 파일
  - 상담원 처리·승인 조건: `backend/services/order_actions.py`(바로 처리), `backend/api/tickets.py`(취소·교환·반품 승인),
    `backend/services/inquiry_context.py`(주문 정보 카드), `backend/services/refund_account.py`(환불 계좌)
  - 고객센터 답변 기한: `backend/services/sla.py`

## 8. 정해지지 않은 것 (FAQ로 답하지 않음)

아래는 정책이 없어서 LLM이 자동으로 답하면 안 되는 내용입니다. 이런 문의는 답변 초안이나 담당자 연결로 처리합니다.

- 보상 (배송 지연·불량에 대한 적립금·쿠폰 지급), 정책 기간을 넘긴 예외 처리 → AI는 약속하지 않고, **상담원이 아래 9장 한도 안에서 판단**
- 특정 상품의 세탁 방법·소재·재입고 날짜 같은 상품별 정보 (상품 상세 페이지 정보가 필요)
- 개별 주문의 배송 위치, 환불 진행 상황 (배송 조회·티켓 도구로 확인)
- 입점·제휴 조건, 개인정보 처리 세부 절차 (담당 부서 안내)

## 9. 상담원 처리 권한 (내부용, 고객 FAQ 아님)

AI는 위 정책대로 안내만 하고, 실제 처리는 상담원이 관리 화면에서 아래 권한 안에서 합니다. 모든 처리는 작업 기록과 문의 처리 이력에 남습니다.

| 항목 | 권한·조건 | 쓰는 곳 |
| --- | --- | --- |
| 본인 확인 | 문의 이메일 = 주문자 이메일일 때만 주문을 바꾸거나 승인 (다르면 반려) | `order_actions.py`, `tickets.py` |
| 바로 처리 (출고 전) | 배송지 변경, 같은 가격의 다른 옵션으로 변경(재고 이동, 열린 취소 요청은 '옵션 변경으로 처리'), 부분 취소 | `order_actions.py` |
| 바로 처리 (그 밖) | 중복 승인 1건 취소, 반품 회수 접수(배송 완료 + 단순 변심 7일·불량 30일 안, 사유 기록) | `order_actions.py` |
| 취소 승인 | 출고 전 주문만 (출고 후면 반려하고 반품 안내) | `tickets.py` |
| 반품 승인 | 반품 회수 접수 뒤에만. 단순 변심이면 왕복 6,000원 차감, 검수 결과 불량이면 체크해서 전액 | `tickets.py` |
| 교환 승인 | 배송 완료 + 30일 안. 교환할 옵션이 모두 품절이면 반려하고 반품 안내 | `tickets.py` |
| 보상 적립금 | 상담원 1회 3,000원까지, 관리자 50,000원까지 (유효 1년) | `order_actions.py` POINT_LIMIT |
| 사과 쿠폰 | 사과 쿠폰 3,000원(2만원 이상)·무료배송 쿠폰: 상담원·관리자, 사과 쿠폰 5,000원(3만원 이상): 관리자만 (30일) | `order_actions.py` COUPONS |
| 환불 계좌 보기 | 맡은 문의만, 볼 때마다 작업 기록 (`refund_account_view`) | `api/inquiry_admin.py` |
| 화면 표시 기준 | 배송 지연 = 출고 후 주문 4일이 지나도 배송 완료 아님, 재고 적음 = 3개 이하 | `policy.py`, `inventory.py` |
